INTERSTELLAR — brauzer o'yini

Ishga tushirish:
  index.html faylini ikki marta bosing (Chrome yoki Edge tavsiya etiladi).
  Internet kerak (three.js kutubxonasi internetdan yuklanadi).
  Telefonda: faylni brauzerda oching, ekranda tugmalar chiqadi (o'ng yuqoridagi ⛶ — to'liq ekran).

Tugmalar (kompyuter):
  W/S gaz, A/D burilish, Strelka yuqori/past, Q/E aylanish, Shift tezlatgich, X gazni 0 qilish
  C kamera (tashqi/kabina), N xarita va avtopilot, L avtomatik qo'nish, F kemadan chiqish/kirish
  Space sakrash, G grafika sifati, M ovoz, sichqoncha sudrash = qarash

Xato bo'lsa ekranning o'ng yuqorisida qizil yozuv chiqadi.
